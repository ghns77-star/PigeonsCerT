# إدارة الحمام وشجرة النسب — تطبيق أندرويد

نسخة أندرويد من برنامج سطح المكتب (Tkinter)، مبنية بـ Capacitor. تعمل **بدون إنترنت**،
وتُحفظ كل البيانات والصور داخل الهاتف.

## الميزات
- سجل الفروخ: إضافة، تعديل، نسخ (بدون رقم حجل وبدون صورة)، حذف متعدد.
- لون الحجل التلقائي حسب تاريخ الفقس (FCI، وآخر 3 أشهر تُحسب للسنة التالية)، وحساب تاريخ الفقس من البيضة (+18 يوماً).
- **صورة الحمامة** لكل فرخ، تُحفظ مع سجله وتظهر في شهادته فقط.
- بحث بسيط وبحث متقدم (معيارين فأكثر، ويشمل البحث باسم الأب/الأم/الأجداد) وترتيب بأي عمود.
- شجرة النسب المرئية.
- **شهادات النسب PDF**: شهادة واحدة أو عدة شهادات في ملف واحد، صفحة لكل فرخ بصورته فقط.
- جدول العلاجات والتطعيمات مع تلوين المتأخر والقريب.
- تصدير / استيراد CSV (يقبل ترميز UTF-8 وWindows-1256 وفاصل `,` أو `;`).
- نسخة احتياطية واستعادة (ملف JSON يتضمن الصور).
- سمة فاتحة/داكنة.

> **انتقال البيانات من برنامج سطح المكتب:** صدّر الفروخ بصيغة CSV من النسخة المكتبية،
> ثم استوردها هنا من القائمة ⋮ ← «استيراد CSV». (الصور لا تُنقل عبر CSV؛ أضفها من شاشة التعديل.)

## بناء ملف APK (الطريقة الأسهل: GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي.
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (أو يبدأ تلقائياً عند الرفع).
3. بعد انتهاء البناء (نحو 5–10 دقائق) افتح التشغيل ونزّل الملف **pigeons-apk**؛ بداخله `app-debug.apk`.
4. انقل الملف إلى الهاتف وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

## البناء على جهازك (بديل)
المتطلبات: Node 20+، JDK 17، Android Studio (للـ SDK).
```bash
npm install
npx cap add android
npx cap sync android
npx cap open android      # ثم Build ← Build APK(s) من Android Studio
```

## ملاحظات
- الـ APK الناتج موقّع بمفتاح تصحيح (debug)؛ يصلح للتثبيت المباشر. للنشر على Google Play تحتاج توقيع Release.
- الأيقونة الافتراضية هي أيقونة Capacitor؛ يمكن تغييرها لاحقاً (مثلاً بأداة `@capacitor/assets`).
- مشاركة PDF/CSV/النسخة الاحتياطية تفتح قائمة المشاركة في أندرويد: اختر «حفظ» أو أي تطبيق (Drive، واتساب، طباعة...).
- التواريخ تُدخل عبر منتقي التاريخ الأصلي في الهاتف (بدل التقويم العربي المخصص في النسخة المكتبية).
- اختبارات المنطق: `npm test`.
